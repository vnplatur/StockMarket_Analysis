# 🚀 CryptoTracker

A lightweight **JavaScript** single-page app for browsing cryptocurrencies — supports **pagination**, **sorting by high/low values**, **marking favorites**, and **quick details** for each coin.

🔗 **Live Demo:** [CryptoTracker](https://vnplatur.github.io/StockMarket_Analysis/)

---

## 📌 Features

- 📊 Browse a list of cryptocurrencies with current price and 24h change
- 📄 Pagination (client-side or server-driven depending on API)
- ↕ Sort by price, market cap, and 24h change (ascending/descending)
- ⭐ Mark/unmark favorites; favorites persist in `localStorage`
- 🔍 Search/filter by coin name or symbol
- 📱 Responsive UI for desktop and mobile
- 🔄 Optional: refresh prices manually or set auto-refresh interval

---

## 🛠 Tech Stack

- **JavaScript (ES6+)**
- **HTML5 & CSS3** (optionally Tailwind / Bootstrap)
- **Fetch API** (or axios) to call a crypto price API (e.g., CoinGecko / CoinMarketCap)
- **localStorage** for favorites and small client-side caching
